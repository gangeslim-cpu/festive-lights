Series Circuit

In a series circuit, there is only one path for the electricity. If any bulb is removed, the path is broken, and no electricity can flow to any other bulb.

Click a bulb to "unscrew" it!

What's Happening?

The "Festive Light Failure" occurs because many cheap light strings are wired in series. This means electrons must pass through every single filament to return to the source. If one filament snaps or a bulb is removed, the continuity is lost.

The Modern Fix

Most modern festive lights use parallel wiring or special bulbs with a "shunt." In a parallel circuit, each bulb has its own direct path to the power source, ensuring the rest of the house stays bright!
